# نام کامپیوتر در شناسنامه‌ها — بستهٔ اصلاح

**نسخه:** ۱.۶۳.۱ · **موضوع:** حذف آدرس IP از نام نمایشی کامپیوتر

---

## مشکل

در کمبوی **«سیستم مرتبط»** فرم ثبت تیکت و در فهرست شناسنامه‌ها، جای نام
کامپیوتر این دیده می‌شد:

```
clint 192.168.1.65
```

دو دلیل که چرا مهم بود:

۱. **ظاهر شناسنامه‌ها** — پر از آدرس IP به‌جای نام.
۲. **ثبت تیکت IT** — انتخاب «سیستم مرتبط» الزامی است و کاربر باید سیستمی را
   انتخاب کند که نامش روی برچسب کیس نوشته شده. هیچ کاربری IP خودش را
   نمی‌داند، پس این فهرست عملاً قابل استفاده نبود.

## نتیجهٔ اصلاح

| نام ثبت‌شده | پیش‌تر | حالا |
|---|---|---|
| `clint 192.168.1.65` | `clint 192` | **`clint`** |
| `pc1 10.1.2.3` | `pc1 10` | **`pc1`** |
| `CLIENT 192.168.1.65` | `client 192` | **`client`** |
| `clint 192.168.1.65.corp.local` | `clint 192` | **`clint`** |
| `pc1 192.168.1.5 CORP` | `pc1 192` | **`pc1`** |
| `CLIENT-192-168-1-65` | `client-192-168-1-65` | **`192.168.1.65`** |
| `reza-pc` | `reza-pc` | `reza-pc` (بدون تغییر) |
| `ADMINIT2.DOMAIN.LOCAL` | `adminit2` | `adminit2` (بدون تغییر) |
| `192.168.1.65` | `192.168.1.65` | `192.168.1.65` (تنها شناسه) |

### ۱.۶۳.۳ — نام دقیقاً مثل سیستم‌عامل

| ورودی | پیش‌تر | حالا |
|---|---|---|
| `MBA4-01` | `mba4-۰۱` | **`MBA4-01`** |
| `MBA4-150` | `mba4-۱۵۰` | **`MBA4-150`** |
| `PC-023` | `pc-۰۲۳` | **`PC-023`** |

دو ایراد رفع شد:

۱. **ارقام نام فارسی می‌شدند** — لایهٔ فارسی‌سازی ارقام حالا نام کامپیوتر را
   «توکن ماشینی» می‌شناسد و دست نمی‌زند. تاریخ و اعداد بقیهٔ متن همچنان
   فارسی می‌شوند.
۲. **پیش‌فرض حروف را کوچک می‌کرد** — حالا پیش‌فرض «حفظ حروف اصلی» است.
   حالت کوچک‌کردن در تنظیمات باقی مانده است.

### IP گم نمی‌شود — «پس‌زمینه» می‌رود

- **tooltip:** ماوس روی نام → نام کامل دیده می‌شود.
- **جستجو:** تایپ IP یا نام کامل، رکورد را پیدا می‌کند.
- **ستون IP:** آدرس کامل در فهرست شناسنامه‌ها هست.

## ابزار تعمیر رکوردهای موجود

```
php tools\normalize_asset_hostnames.php
```

خروجی نمونه:

```
  رکوردهای بررسی‌شده : 12
  قابل پاک‌سازی      : 4
  فقط IP (رها می‌شود) : 1

  شناسه نام کنونی                    نام تازه
  10     clint 192.168.1.65           clint
  11     PC1 10.1.2.3                 PC1
  12     DOMAIN-ADMINIT2              ADMINIT2

  ⚠️  این رکوردها فقط IP دارند و نام واقعی ندارند:
     شناسه 13     IP: 192.168.1.99
```

**رکوردی که فقط IP است دست نمی‌خورد** — نام واقعی ندارد و باید از برچسب کیس
یا با اسکن دامنه پُر شود.

برای اعمال:

```
php tools\normalize_asset_hostnames.php --apply
```

## یک باگ دیگر که همان‌جا پیدا شد

کلید تشخیص تکراری (`hostname_key`) پس از **تغییر نام** به‌روز نمی‌شد. نتیجه:
اگر نام سیستم را ویرایش می‌کردید و بعد همان سیستم از دامنه اسکن می‌شد،
سامانه فکر می‌کرد سیستم تازه‌ای است و **رکورد تکراری** می‌ساخت.

در ۶ نقطه رفع شد:

| فایل | نقطه |
|---|---|
| `actions/asset-actions.php` | ذخیرهٔ فرم شناسنامه |
| `inventory.php` | ۴ نقطهٔ به‌روزرسانی خودکار |
| `domain-scan.php` | ثبت و به‌روزرسانی از اسکن |

---

## اگر نام روی کیس چیز دیگری است

نام نمایشی `clint` است — همان چیزی که سامانه می‌دانست. اگر برچسب روی کیس
چیز دیگریست، نام درست را یک‌بار وارد کنید:

```
شناسنامه رایانه ← «تکمیل دستی» ← فیلد «نام کامپیوتر»
```

از آن به بعد همان نام در همهٔ فهرست‌ها و کمبوها دیده می‌شود و کلید هویت هم
خودکار به‌روز می‌شود.
