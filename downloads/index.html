Ticket نسخهٔ ۱.۶۱.۱۰ — موجودی عمیق کل دامنه

R29 اسکن سراسری Active Directory را برای تمام computer objectهای یافته‌شده صف می‌کند و دسته‌های بیشتری از جزئیات سیستم را با WMI/CIM جمع می‌کند.

  • جست‌وجوی صفحه‌بندی‌شدهٔ AD بدون سقف ضمنی ۳۰۰۰ سیستم؛ سقف ۹۰۰ فقط برای انتخاب دستی است.
  • درایورها و دستگاه‌های PnP، سرویس‌ها، پردازه‌ها، startup، shareها، حساب‌ها، HotFixها، امنیت و شاخص‌های سلامت ذخیره‌سازی به Inventory افزوده شده‌اند.
  • همان یک حساب Domain Admin را برای مقصدهای مجاز استفاده کنید؛ ساخت حساب محلی برای هر PC لازم نیست.
  • برابری کامل با TNI ادعا نمی‌شود؛ دادهٔ جزئی درایورهای اختصاصی TNI ممکن است در WMI/CIM موجود نباشد. بدون migration و بدون تغییر دادهٔ تولیدی.
