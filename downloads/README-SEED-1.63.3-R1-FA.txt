بستهٔ ابزار دادهٔ نمونهٔ غذا — نسخهٔ سازگار 1.63.3، بازنگری r1
تاریخ بسته: 2026-11-19

محتوا
- tools/seed_test_data.php: ساخت دادهٔ حجیمِ تست برای گزارش‌های غذا و گزارش کاربران دامین.

این بسته به‌روزرسانی نرم‌افزار وب نیست و VERSION سامانه را تغییر نمی‌دهد؛ مهاجرت یا فایل اجرایی دیگری ندارد.

پیش‌نیاز
- PHP CLI و MySQL/MariaDB.
- پایگاه‌دادهٔ تست با ساختار هم‌نسخهٔ سامانه؛ برای گزارش‌های تطبیق/فاکتور/واقعیت مهمان، جداول مهاجرت‌های غذا (از جمله 022 و 038) باید موجود باشند.

اجرا
1. فایل tools/seed_test_data.php را در ریشهٔ سامانه قرار دهید.
2. ابتدا در پایگاه‌دادهٔ تست اجرا کنید:
   php tools/seed_test_data.php --test-env
3. برای بازسازی داده‌هایی که همین اسکریپت قبلاً ساخته است:
   php tools/seed_test_data.php --test-env --fresh

--fresh فقط داده‌هایی را که مانیفست همین ابزار ثبت کرده پاک می‌کند؛ با این حال آن را فقط روی پایگاه‌دادهٔ تست اجرا کنید. اسکریپت عمداً برای محیطی که --test-env را نپذیرد متوقف می‌شود.

دادهٔ ساخته‌شده شامل سفارش ناهار و شام، فیش‌های چاپی و خودکار، سفارش‌های لغوشده، غیبت‌ها، درخواست‌ها و فیش مهمان، ردیف «بدون جایگاه»، تطبیق روزانهٔ خرید/دریافت/توزیع، فاکتورهای ماهانهٔ PDF نمونه، کارت گروهی و حساب‌های آزمایشی LDAP/پرسنل غذای قدیمی است.

فاکتورهای PDF ساختگی‌اند و فقط برای نمایش گزارش و دانلود در محیط تست ساخته می‌شوند؛ به‌عنوان سند واقعی مالی استفاده نشوند.
