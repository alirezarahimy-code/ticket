# مدیریت درخواست غذای مهمان — ۱.۶۲.۴۴

بستهٔ تجمعی برای نصب روی نسخهٔ پایهٔ **۱.۶۲.۴۲**؛ شامل اصلاحات ذخیره/چاپ فیش گروهی ۱.۶۲.۴۳ و مدیریت درخواست غذای مهمان.

## امکانات
- مدیر ثبت‌کننده می‌تواند درخواست خودش را ویرایش، لغو یا حذف کند.
- مدیر پشتیبانی و ادمین اصلی می‌توانند درخواست‌های مهمان را مدیریت کنند.
- نام مدیر ثبت‌کننده در فهرست دیده می‌شود تا درخواست‌ها قابل تشخیص باشند.
- درخواست فعال تا مهلت روز جاری قابل ویرایش است؛ روزهای گذشته قفل‌اند.
- «لغو» درخواست را با وضعیت لغوشده نگه می‌دارد؛ «حذف» رکورد را حذف قطعی می‌کند و تلاش Audit برای ثبت مقدار قبلی انجام می‌شود.
- عملیات در سمت سرور مجوزسنجی می‌شود؛ صرفاً پنهان‌کردن دکمه، کنترل دسترسی نیست.
- اصلاحات گروهی ۱.۶۲.۴۳ نیز همراه بسته‌اند: مسیر API صفحهٔ اصلی، تأیید ذخیره از پایگاه‌داده، عنوان گروه جدا، اندازه‌های مستقل و فاصلهٔ منو/اعضا.

## پایگاه‌داده و نصب
- مهاجرت تازه ندارد؛ از جدول‌ها و ستون‌های موجود استفاده می‌کند.
- فقط روی نسخهٔ **۱.۶۲.۴۲** نصب شود و پیش از نصب بکاپ بگیرید.
- بسته روی سرور نصب نشده است؛ پس از نصب، عملیات باید در سامانهٔ واقعی تأیید شود.
