### ج) استخراج شناسنامه

> «استخراج شناسنامه را بررسی کردی؟ درست استخراج می‌شود یا هنوز خطا دارد؟»

**پاسخ:** نگاشت داده **درست** است (۱۰ فیلد از ۱۰)، ولی مسیر ذخیره سه ایراد
داشت که استخراج را می‌شکست:

1. **برخورد کلید یکتا** — اگر نام برگشتی از اسکن قبلاً روی رکورد دیگری بود،
   `Duplicate entry … uq_assets_hostname_key` **کل** UPDATE را برمی‌گرداند.
2. **نام کامپیوتر بی‌صدا بازنویسی می‌شد.**
3. **سریال و مدل خودِ دستگاه هیچ فیلدی در شناسنامه نداشتند** — هر چه استخراج
   می‌خواند، در فرم دیده نمی‌شد.

هر سه اصلاح شد. اثبات در پایگاه‌داده:

```
قبل → serial_number = NULL, model = NULL, cpu = NULL, memory_mb = NULL
بعد → serial_number = 'CZC1234ABC', model = 'EliteDesk 800 G6',
      cpu = 'Intel(R) Core(TM) i7-10700…', memory_mb = 16384
ذخیره: موفق (۱۳)   ·   hostname: دست‌نخورده ماند ✅
```

فرم شناسنامه حالا دارد:
`profile[machine_serial]` و `profile[machine_model]`.

> **نکتهٔ صادقانه:** استخراج *شبکه‌ای* فقط روی سرور Windows و با HTTPS کار
> می‌کند. روی Linux همین پیش‌بررسی پیام روشن می‌دهد؛ این رفتار درست است.
