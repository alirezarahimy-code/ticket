# گزارش تغییرات ۱.۶۲.۵۷ — اصلاحات درخواست‌شده

این بسته برای نصب روی نسخهٔ **۱.۶۲.۵۶** آماده شده و فقط فایل‌های برنامه را به‌روزرسانی می‌کند؛ هیچ migration یا تغییر پایگاه‌داده‌ای ندارد.

## تغییرات

- دکمهٔ افزودن اداره در کارت معاونتِ نمودار سازمانی.
- اصلاح بارگیری و نمایش گزارش سفارش‌های امروز و گروه‌های غذا؛ دو نسخهٔ `food-menu.js` همگام‌اند.
- فعال‌سازی ثبت درخواست غذای مهمان براساس مجوزهای نقش سامانه، بدون الزام عضویت در نمودار سازمانی؛ انتساب معاونت اختیاری است و درخواست بدون معاونت به‌صورت مرکزی ثبت می‌شود.
- بازبینی تفکیک مشاهده و ویرایش: مشاهده خواندنی است و ویرایش فقط عملیات تغییردهندهٔ همان بخش را فعال می‌کند؛ مسیرهای API نیز مجوز ویرایش را سمت سرور بررسی می‌کنند. مجوزهای مستقل گزارش، کارکنان، گروه‌ها و قابلیت‌های جداگانه همچنان مستقل می‌مانند.
- هماهنگ‌سازی راهنما و FAQ و افزایش پین‌های cache فایل‌های تغییرکرده.

## فایل‌ها و پایگاه‌داده

این بسته شامل ۱۱ فایل برنامه و راهنمای تغییرات است. فهرست migration خالی است؛ هیچ DDL هنگام بارگذاری صفحه اضافه نشده و هیچ پایگاه‌داده، سرور یا migration در جریان این آماده‌سازی اجرا نشده است. نسخهٔ بررسی‌شدهٔ نمودار سازمانی V8 داخل بسته نیست.

## آزمون‌ها و محدودیت‌های بررسی

- ۸۲ آزمون ایستای مرتبط موفق شدند؛ بررسی نحوی پنج فایل JavaScript با `node --check` و همسانی دو نسخهٔ `food-menu.js` نیز موفق بود.
- مجموعهٔ کامل Python شامل ۱۶۱ آزمون بود و همگی موفق شدند. آزمون startup به‌روز شد تا اجرای موازی APIهای چاپگر/کارکنان از طریق `Promise.all(jobs)` را مطابق پیاده‌سازی فعلی بررسی کند.
- PHP CLI، آزمون مرورگر و پایگاه‌دادهٔ تست در محیط موجود نبودند؛ بنابراین آزمون PHP/runtime/DB انجام نشده است.

**این یک بستهٔ قابل‌بررسی برای اعمال توسط مدیر سامانه است؛ در این آماده‌سازی هیچ نصب یا deploy انجام نشده است.** ابتدا پشتیبان بگیرید و ترجیحاً روی staging/clone بررسی کنید.
