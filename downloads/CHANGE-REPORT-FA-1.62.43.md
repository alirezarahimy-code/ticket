# بستهٔ اصلاح چاپ گروهی فیش — ۱.۶۲.۴۳

این بسته برای به‌روزرسانی از نسخهٔ **۱.۶۲.۴۲** ساخته شده است.

## اصلاحات
- تضمین وجود بوت‌استرپ API در صفحهٔ اصلی سامانه و مسیر ذخیرهٔ طراحی گروهی.
- ذخیرهٔ قالب گروهی و حالت چاپ فقط پس از خواندن مجدد و تأیید مقدار پایگاه‌داده موفق اعلام می‌شود.
- خطای HTTP 404 دیگر به اشتباه به «سرویس مستقل» نسبت داده نمی‌شود و مسیر واقعی API را نشان می‌دهد.
- حفظ طراحی مستقل گروهی با فیلد مستقل «عنوان گروه»، کنترل اندازهٔ جداگانهٔ عنوان منو و نام اعضا، و فاصلهٔ ۱٫۵ میلی‌متری بین عنوان منو و نخستین نام.
- پیش‌نمایش واقعی سرور و خروجی چاپ شبکه/صف ویندوز از مدل قالب گروهی مستقل استفاده می‌کنند.

## دیتابیس و احتیاط
- مهاجرت دیتابیس: **ندارد**؛ فقط تنظیمات موجود در جدول `settings` خوانده/ذخیره می‌شوند.
- فایل‌ها: بکاپ پیش از به‌روزرسانی باید از خودِ updater گرفته شود.
- این بسته را فقط روی **۱.۶۲.۴۲** نصب کنید؛ برای نسخهٔ دیگری، شمارهٔ نسخهٔ نصب‌شده را اول تطبیق دهید. نصب روی نسخهٔ قدیمی‌تر می‌تواند اصلاحات میانی را جا بیندازد.
- بسته روی سرور نصب نشده است؛ پس از نصب، ذخیرهٔ قالب و پیش‌نمایش/چاپ واقعی باید در همان سامانه تأیید شود.
