# راهنمای اسکریپت آزمون جامع سامانه

فایل: `tools/system_loadtest.php`

این اسکریپت سامانه را روی سرور واقعی می‌سنجد و دو گزارش می‌سازد که می‌توانید
برایم بفرستید:

```
storage\logs\loadtest-report-<زمان>.txt     ← خواندنی برای شما
storage\logs\loadtest-report-<زمان>.json    ← برای تحلیل دقیق
```

---

## ⚠️ قاعدهٔ ایمنی

**اسکریپت به‌صورت پیش‌فرض هیچ چیزی نمی‌نویسد.** بدون سوییچ فقط بررسی
فقط‌خواندنی انجام می‌دهد. برای ساخت دادهٔ آزمایشی باید صریحاً `--write --confirm`
بدهید، و برای حذف باید صریحاً `--cleanup --confirm` بدهید.

سه محافظ دیگر:

| محافظ | توضیح |
|---|---|
| **پیشوند اختصاصی شماره** | شمارهٔ درخواست‌های آزمایشی با پیشوند جدا (`ZZTEST`) ساخته می‌شود. شمارندهٔ واقعی سازمان شما **دست نمی‌خورد** و شماره‌های واقعی نمی‌پرند. |
| **مانیفست** | هر ردیفی که ساخته می‌شود در `storage\logs\loadtest-manifest.json` ثبت می‌گردد. پاک‌سازی **فقط** همان شناسه‌ها را حذف می‌کند. |
| **ادامه به‌جای بازنویسی** | اگر دوبار اجرا کنید، مانیفست ادامه پیدا می‌کند تا ردیف‌های اجرای قبلی یتیم نشوند. |

هیچ دادهٔ موجودی خوانده‌نشده تغییر نمی‌کند و هیچ ردیف غیرآزمایشی حذف نمی‌شود.

---

## مرحله ۱ — اجرای ایمن (اول این را بزنید)

در `cmd` داخل پوشهٔ نصب:

```
cd C:\xampp\htdocs\ticket
C:\xampp\php\php.exe tools\system_loadtest.php
```

هیچ داده‌ای ساخته نمی‌شود. خروجی را بفرستید. این به‌تنهایی این‌ها را روشن می‌کند:

- نسخهٔ واقعی PHP و افزونه‌های فعال
- **کدام اصلاحات روی نصب شما حاضرند و کدام نیستند** (بخش B)
- شماره‌های تکراری یا خالی در دادهٔ فعلی
- کوئری‌های کند و ایندکس‌های غایب
- چرا ممیزی سلامت اجرا نمی‌شود

## مرحله ۲ — آزمون با ۲۵۰ کاربر

```
C:\xampp\php\php.exe tools\system_loadtest.php --write --confirm
```

۲۵۰ کاربر و ۵۰۰ درخواست آزمایشی می‌سازد و زمان ثبت، تکرار شماره و افت
کارایی را اندازه می‌گیرد. داده باقی می‌ماند تا در رابط کاربری هم ببینید.

تعداد دلخواه:

```
C:\xampp\php\php.exe tools\system_loadtest.php --write --confirm --users=250 --tickets=1000
```

## مرحله ۳ — پاک‌سازی

```
C:\xampp\php\php.exe tools\system_loadtest.php --cleanup --confirm
```

فقط ردیف‌های ثبت‌شده در مانیفست و ردیف شمارندهٔ آزمایشی حذف می‌شوند.

---

## اگر `php.exe` پیدا نشد

مسیر PHP نصب خود را جایگزین کنید. مسیرهای رایج:

```
C:\xampp\php\php.exe
C:\php\php.exe
```

برای یافتن: `where php` یا در XAMPP Control Panel → Explorer → پوشهٔ `php`.

---

## آنچه باید برایم بفرستید

فایل `.txt` کافی است. اگر حجمش زیاد بود یا می‌خواهید تحلیل دقیق‌تر باشد،
فایل `.json` را هم بفرستید.

> اگر نمی‌خواهید نام کاربران واقعی بیرون برود: بخش H چند نام نقش را نشان
> می‌دهد ولی نام کاربری یا رمز چاپ نمی‌کند. هیچ رمز، توکن یا محتوای
> درخواست در گزارش نوشته نمی‌شود.
