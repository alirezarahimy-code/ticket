# نام کامپیوتر در شناسنامه — «بدون اضافه و کم»

**نسخه:** ۱.۶۳.۱ · **موضوع:** چرا `MBA4-01` به `mba4-۰۱` تبدیل می‌شد و چطور رفع شد

---

## ۱) شکایت

> «برای سیستم‌ها یک الگو استفاده کردم: `mba4-01` الی `mba4-150`. تو شناسنامه
> دقیقاً همین‌هایی که به‌عنوان computer name تو سیستم‌عامل مشخص شده نمایش داده
> می‌شود بدون اضافه و کم؟ تو فرم ثبت تیکت چی؟»

پاسخ صادقانه: **قبل از این اصلاح، نه.**

---

## ۲) دو ایراد واقعی

### ایراد ۱ — ارقام نام فارسی می‌شدند

سامانه یک لایهٔ سراسری دارد که ارقام متن را فارسی می‌کند
(`lib/fa-digits.php`) تا تاریخ‌ها و اعداد در رابط فارسی دیده شوند. اما این
لایه **نام کامپیوتر را هم** دست می‌زد:

```
MBA4-01   →   MBA4-۰۱     ← غلط
```

این بدترین نوع خطاست چون:

- برچسب روی کیس `MBA4-01` است، نه `MBA4-۰۱` — تطبیق چشمی ممکن نیست.
- کپی و جست‌وجو می‌شکند.
- با نامی که در Active Directory هست یکی نیست.

### ایراد ۲ — حروف کوچک می‌شدند

پیش‌فرض نمایش `short_lower` بود، یعنی همیشه حروف کوچک می‌شدند:

```
MBA4-01   →   mba4-01     ← با برچسب کیس نمی‌خواند
```

---

## ۳) اصلاح

### الف) ارقام نام، ماشینی می‌مانند

IP و ایمیل از قبل به‌عنوان «توکن ماشینی» از فارسی‌سازی مستثنا بودند. حالا
**نام کامپیوتر** هم به همان فهرست اضافه شد:

```
MBA4-01                  → MBA4-01       ✅
MBA4-150                 → MBA4-150      ✅
PC-023                   → PC-023        ✅
```

و بقیهٔ متن همچنان فارسی می‌شود (این مهم است — نمی‌خواهیم فارسی‌سازی بشکند):

```
سیستم MBA4-01 در تاریخ 1403/08/14   →  سیستم MBA4-01 در تاریخ ۱۴۰۳/۰۸/۱۴   ✅
تعداد 5 پرس برای MBA4-150           →  تعداد ۵ پرس برای MBA4-150           ✅
```

### ب) پیش‌فرض: حفظ حروف اصلی

پیش‌فرض از `short_lower` به `short` عوض شد:

| حالت | نتیجه | وضعیت |
|---|---|---|
| `short` (**پیش‌فرض**) | `MBA4-01` | دقیقاً مثل سیستم‌عامل |
| `short_lower` | `mba4-01` | انتخابی |
| `full` | `MBA4-01.CORP.LOCAL` | انتخابی |

ⓘ نصب‌هایی که قبلاً `short_lower` را **صریح** ذخیره کرده‌اند، همان را حفظ
می‌کنند. برای برگشت به بزرگ/کوچک‌کردن خودکار:
**تنظیمات ← اطلاعات سامانه ← ظاهر نام کامپیوترها**.

## ۴) نتیجه — همه‌جا یکسان

در سامانهٔ زنده با ۸ کامپیوتر الگوی شما تست شد:

### فهرست شناسنامه‌ها (`page=assets` — عکس ۲)

```
MBA4-01  ·  MBA4-02  ·  MBA4-23  ·  MBA4-25  ·  MBA4-26  ·  MBA4-27
MBA4-28  ·  MBA4-150
```

### فرم ثبت تیکت — کمبوی «سیستم مرتبط»

```
MBA4-01 · MBA4-02 · MBA4-23 · MBA4-150 · ...
```

### صفحهٔ جزئیات شناسنامه

```
عنوان: «شناسنامه رایانه MBA4-01»
ردیف «نام کامپیوتر»: MBA4-01
```

### فرم ویرایش شناسنامه

```
فیلد «نام کامپیوتر»: MBA4-01
```

**هیچ‌کدام ارقام فارسی ندارند، هیچ‌کدام کوچک نشده‌اند.**

## ۵) جزئیات نام کامل دامنه

اگر نام در AD به شکل کامل باشد، بخش دامنه حذف می‌شود ولی خود نام
دست‌نخورده می‌ماند:

| ورودی | نمایش |
|---|---|
| `MBA4-01.CORP.LOCAL` | `MBA4-01` |
| `MBA4-150.corp.local` | `MBA4-150` |
| `MBA4-01$` (حساب کامپیوتر AD) | `MBA4-01` |
| `MBA4-01 192.168.10.11` | `MBA4-01` (IP حذف) |
| `192.168.10.11` | `192.168.10.11` (تنها شناسه — دست‌نخورده) |

نام کامل همیشه در tooltip روی نام می‌ماند.

## ۷) دربارهٔ عکس ۱

عکسی که فرستادید ستون‌های **SMB / WinRM / DCOM / پینگ** دارد و دکمه‌های
«ورود کامپیوترهای دامنه» و «آماده‌سازی سیستم‌های مقصد» را نشان می‌دهد.

**این جدول در نسخهٔ فعلی کد وجود ندارد.** فهرست شناسنامه‌ها در این نسخه
ستون‌های زیر را دارد:

> سیستم · معاونت · IP · شبکه · وضعیت استخراج · آخرین استخراج · شناسنامه

و دکمه‌های آن: «ورود کامپیوترهای دامنه» · «حساب استخراج شبکه» ·
«دانلود Excel همهٔ سیستم‌ها». دکمهٔ محلی جداگانه حذف شده است؛ برای برداشت سرور سامانه، رکورد سرور را در فهرست انتخاب کنید و «استخراج اطلاعات سیستم‌های انتخاب‌شده» را اجرا کنید.

یعنی عکس ۱ از یک نسخهٔ **قدیمی‌تر** است (یا از صفحه‌ای که در این نسخه حذف
شده). عکس ۲ — که صفحهٔ واقعی فعلی است — صفحه‌ای است که در همین تغییر
درست شد.

اگر جدول SMB/WinRM/DCOM را در سامانهٔ خود می‌بینید و می‌خواهید بماند،
بگویید تا در نسخهٔ فعلی بازسازی شود. آن جدول یک قابلیت **جدا** از نام
کامپیوتر است.

## ۸) نصب

۱. محتوای پوشهٔ `files/` را روی پوشهٔ نصب کپی کنید.
۲. مرورگر را ببندید و باز کنید.
۳. اگر پیش‌فرض قدیمی (`short_lower`) روی سامانه ذخیره شده و نام‌ها را کوچک
   می‌بینید: **تنظیمات ← اطلاعات سامانه ← ظاهر نام کامپیوترها** و گزینهٔ
   «فقط نام، دقیقاً با همان حروف ثبت‌شده» را انتخاب کنید.

**بدون مهاجرت. بدون تغییر جدول. بدون تغییر داده.**
