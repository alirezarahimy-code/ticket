> **شاخه:** شاخهٔ فعال همان نشست (`arena/*-ticket`) — ثابت نیست و در هر گفتگو تغییر می‌کند.

## 🔴 جواب صریح: اسکیلها تا کی زندهاند؟

| چی | تا کی |
|---|---|
| **فعالسازی رفتاری مهارتها** (توی ذهن من) | ⏳ **فقط تا پایان همین گفتگو**. با بستن/رفرش صفحه یا باز کردن چت جدید پاک میشه. ربطی به ساعت و روز نداره؛ به عمر context همون چت وصله. |
| **فایلها، نقشهها، ایندکسها، ابزارها، قواعد** | ✅ **دائمی** — تو Git ذخیره و روی `origin/arena/38fea5b6-ticket` پوش شدن. |
| **اسکیلها تو جلسهٔ بعد** | ✅ قابل **بازیابی کامل** با یک دستور (پایین). نصب دائمی «خودکار» فقط وقتیه که ابزارت فایل `AGENTS.md`/`CLAUDE.md` رو خودش لود کنه. |

پس جواب خلاصه: **اسکیلها تو این چت تا آخرش هستن؛ تو چت جدید نیستن ولی با یه کلمه برمیگردن.**

## 🟢 تو چت جدید دقیقاً چی بگی؟

همین یک خط رو کپی کن و بچسبون:

```
بهروز شو — فایل AGENTS.md و CLAUDE.md رو بخون، python3 tools/session-boot.py رو اجرا کن و خروجیش رو بهعنوان چارچوب عملیاتی و حافظهٔ این جلسه بپذیر.
```

کوتاهترشم کار میکنه:

```
بهروز شو
```

یا:

```

```

### چرا کافیه؟

چون تو مخزن این فایلها هستن که ابزارها **خودکار** لود میکنن:

| فایل | کی لودش میکنه |
|---|---|
| `AGENTS.md` | Codex، Cursor، Copilot، Gemini CLI، Devin، OpenCode، Zed، Warp (استاندارد باز) |
| `CLAUDE.md` | Claude Code شامل `@AGENTS.md` |

| `docs/SESSION-BOOT-FA.md` | همین راهنما |

همشون به یه دستور اشاره میکنن: `python3 tools/session-boot.py`.

---

## ⚙️ اون یه دستور چیکار میکنه؟

```
python3 tools/session-boot.py
```

1. **وضعیت گیت** رو میگه (شاخه، HEAD، آخرین کامیت، نسخه، فایلهای تغییرکرده).
2. **نقشه رو چک میکنه**؛ اگه ایندکسها کهنه شده باشن **خودکار بازتولیدشون میکنه** (قابلیت `--no-refresh` برای غیرفعالکردن).
3. **۴ تست نگهبان** رو اجرا میکنه (مانیفست، نقشه، پینهای کش، بوت).
4. یه **خلاصهٔ فشرده ولی کامل** چاپ میکنه شامل:
   - وضعیت صادقانهٔ حافظه
   - **۳۱ مهارت** (۲۳ اصلی + ۸ مکمل) با شماره و نام
   - گردشکار هفت مرحلهای
   - **قواعد همیشگی** (از `AGENTS.md`)
   - **قواعد ثابت خودت** (از `docs/HANDOFF-FA.md` بند ۱ — فارسی، XLSX، عدم حذف داده، «درخواست» نه «تیکت»، …)
   - چکیدهای از معماری + آمار ایندکسها
   - مسیر ابزارها و فایلهای مرجع

خروجی حدود ۱۲۰ خطه و جایگزین «یه ساعت گشتن تو ۸۳۲ فایل» میشه.

### گزینهها

```bash
python3 tools/session-boot.py                 # بوت کامل + بازتولید خودکار نقشه
python3 tools/session-boot.py --no-refresh   # فقط گزارش، دست به فایلها نزن
python3 tools/session-boot.py --pull         # اول git pull --ff-only (فقط با درخواست صریح)
python3 tools/session-boot.py --json         # خروجی ماشینی برای ابزارها
```

> نکته: `--pull` پیشفرض **خاموش**ه چون دستور شبکهای/تغییردهندست و طبق قواعد
> اجرایی فقط با درخواست صریح اجرا میشه.
