# گزارش پایگاه داده و Migration — نسخه 1.62.76

- Base دقیق: `1.62.75`؛ Target: `1.62.76`.
- Migration جدید برای این انتشار: **ندارد**.
- تغییر Schema دیتابیس در این انتشار: **ندارد**.
- فایل‌های تاریخی Logging از `019` تا `025` در ZIP Update همراه بسته‌بندی شده‌اند تا سورس/مخزن نصب‌شده این فایل‌ها را حفظ کند؛ این فایل‌ها در `manifest.files` هستند، نه `manifest.migrations`.
- بنابراین Updater آن‌ها را در مسیر `migrations/` کپی می‌کند، اما هیچ‌یک را در ارتقای 1.62.75 به 1.62.76 اجرا نمی‌کند.
- اجرای مجدد 019 تا 025 با نسخه جدید Updater می‌تواند ثبت ledger را با نسخه متفاوت ایجاد کند؛ پس از روی `schema_updates` فقط سابقه اجرا را بررسی کنید و اجرای مجدد خودکار ممنوع است.
- Migration `025` متعلق به مسیر ارتقای `1.62.74` به `1.62.75` است. در بسته Update نهایی 1.62.75 به‌عنوان Migration اجرایی تعریف شده بود. اگر در دیتابیس مقصد اجرا نشده باشد، این موضوع باید جداگانه روی Clone/Staging و پس از بررسی Schema تعیین تکلیف شود.
- گزارش کامل فایل‌ها، منطق بسته‌بندی و پرس‌وجوی پیش‌پرواز: `docs/MIGRATION-COMPATIBILITY-1.62.76-FA.md`.

**وضعیت:** بسته Update فایل‌های تاریخی Migration را حفظ می‌کند؛ اجرای واقعی دیتابیس مقصد و تأیید ledger در این محیط انجام نشده است. Production تأیید نشده است.
