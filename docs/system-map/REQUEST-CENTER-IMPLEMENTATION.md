# یادداشت اجرای مرکز درخواست‌ها

این یادداشت وضعیت واقعی برش اجرایی Request Center را ثبت می‌کند. این فایل سند وضعیت ماژول است و جایگزین نقشهٔ ماشینی سراسری سامانه نیست.

- شاخهٔ اجرایی: `feature/request-center-module-1.62.88`
- Commit اجرایی فعلی: `4c6888f1c278c3a38129cff23c7dcad6144316f3`
- ورودی مستقل: `request-center.php`
- Repository خواندنی: `modules/request-center/RequestCenterRepository.php`
- سرویس متمرکز گذار وضعیت: `modules/request-center/WorkflowService.php`
- ممیزی As-Is: `docs/architecture/REQUEST-CENTER-AS-IS-AUDIT-FA.md`
- قرارداد CI اختصاصی: `.github/workflows/request-center-contract.yml`

## پیاده‌سازی‌شده در این برش

- فهرست و جزئیات مستقل با استفاده از احراز هویت، مجوز و scope فعلی سامانه.
- فیلتر پارامتری شماره/عنوان، وضعیت، اولویت و حوزهٔ خدمت.
- Workspace درخواست‌دهنده با محدودسازی اضافی به شناسهٔ کاربر جاری.
- Workspace کارشناس با صف شخصی بر پایهٔ `assigned_to` و صف گروهی مشروط به `queue.view`؛ هر دو همچنان در محدودهٔ `ticket_scope()` هستند. مسیرهای صفحه‌بندی، بازگشت از جزئیات و پاک‌کردن فیلترها Workspace جاری را حفظ می‌کنند.
- انتقال نخستین مجموعهٔ مسیرهای تغییر وضعیت به `RequestCenterWorkflowService`؛ سرویس در تراکنش فراخواننده ردیف را قفل و وضعیت و guardهای هم‌زمانی را بررسی می‌کند.
- آزمون‌های SQLite و آزمون integration روی MariaDB 10.11 برای preflight، Repository و WorkflowService؛ آخرین اجرای Request Center Contract روی commit فوق موفق است.

## هنوز انجام‌نشده

- چهار Workspace کامل و مستقل نیستند؛ نماهای سوپروایزر و مدیر فعلاً از scope و فیلترهای عمومی استفاده می‌کنند.
- فرم مستقل ایجاد درخواست، عملیات ویرایش، پاسخ، ارجاع، Claim، تصمیم سوپروایزر و مدیریت کامل پیوست‌ها هنوز از مسیرهای سازگار legacy استفاده می‌کنند.
- تقویم رسیدگی، SLA/OLA عملیاتی در Workspaceها، گزارش‌ها و پیکربندی اختصاصی ماژول تکمیل نشده‌اند.
- آزمون end-to-end روی نسخه و دادهٔ واقعی MariaDB نصب‌شدهٔ کاربر اجرا نشده است.
- نقشهٔ ماشینی سراسری در بخش بعدی همین یادداشت بازتولید و guardهای مخصوص آن موفق شده‌اند. اجرای کامل CI عمومی روی commit پس از بازتولید نقشه هنوز تأیید نشده است.

## تازگی نقشهٔ سراسری

پس از آخرین تغییرات کد، نقشهٔ ماشینی سامانه در commit فوق بازتولید شد. اجرای `tools/build_system_map.py --check` و `tests/test_system_map_static.py` موفق بود: ۱۱۷۰ فایل، ۵۵۵۸ نماد، ۴۱۴ روت، ۸۴ جدول، ۱۲۰ بستهٔ به‌روزرسانی و ۳۶ حوزهٔ ویژگی. آزمون بلوک‌های کد نیز با موفقیت گذشت. این به‌روزرسانی صرفاً ایندکس مستندات است و منطق هیچ ماژول دیگری را تغییر نمی‌دهد.

## دروازهٔ انتشار

این شاخه برای بازبینی فنی و ادامهٔ توسعه است، نه برای نصب یا ادغام نهایی. تا تکمیل موارد بالا، رفع guard سراسری CI با حفظ محدودهٔ تغییرات، آزمون رگرسیون و بازیابی، و تأیید نسخهٔ واقعی MariaDB، نباید به‌عنوان بستهٔ انتشار عملیاتی استفاده شود. هیچ تغییری در `main` یا سامانهٔ عملیاتی اعمال نشده است.
