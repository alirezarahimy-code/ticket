# الحاقیه تحویل داشبورد گرافیکی Logging

تاریخ ساخت: 2026-11-04  
نسخه برنامه: `1.62.73`  
مبنای کد: Full Source فازهای ۵ و ۶

## آنچه اضافه شد

- صفحه مستقل `index.php?page=logging-dashboard` با کنترل دسترسی `system.health` و ثبت رویداد منع دسترسی.
- نمایش KPIهای خطا/بحرانی و هشدار ۲۴ ساعت، Issueهای باز/درحال بررسی/حل‌شده و Dead Letter.
- نمودار ساعتی ۲۴ ساعت و نمودار روزانه بازه ۱، ۷، ۱۴ یا ۳۰ روز؛ رسم با SVG داخلی و بدون CDN، سرویس خارجی یا کتابخانه وابسته به اینترنت.
- تفکیک رخداد بر اساس شدت و نمایش ماژول‌های پرتکرار.
- نمایش سلامت دیتابیس، وضعیت آخرین اجرای موفق Worker، صف اضطراری، فایل‌های processing و rewrite-temp، Dead Letter و آمار صف اعلان‌ها.
- فهرست بررسی‌های سلامت موجود سامانه و جدول ۱۲ رخداد اخیر.
- تازه‌سازی صفحه هر ۶۰ ثانیه فقط وقتی صفحه در مرورگر قابل مشاهده است.
- نمایش «نامشخص» برای داده‌های دیتابیسی در زمان قطع DB؛ عدم تبدیل خطای خواندن به مقدار صفر.
- پشتیبانی از نمایشگرهای کوچک و تم‌های روشن/تاریک با CSS محلی.

## امنیت و داده

داشبورد از مجوز `system.health` استفاده می‌کند. پیام رخداد در جدول با تابع پالایش تشخیصی نمایش داده و سپس HTML-escape می‌شود. خروجی هیچ SQL خام، بدنه درخواست، رمز یا توکن را نمایش نمی‌دهد. صفحه endpoint عمومی ندارد و هیچ داده‌ای به سرویس بیرونی ارسال نمی‌کند.

## نتایج آزمون این الحاقیه

- PHP lint فایل داشبورد و نقطه ورود: موفق.
- آزمون SVG محلی: ۶ از ۶ موفق.
- آزمون ایستای داشبورد: ۶ از ۶ موفق.
- مجموعه آزمون‌های مرتبط قبلی Logging/System Health: ۴۳ موفق و ۴ مورد Skip در اجرای جداگانه.

## محدودیت پذیرش

در محیط ساخت حاضر افزونه `pdo_mysql` و `ZipArchive` موجود نیست و سرویس MySQL/MariaDB، Windows Server، IIS و Task Scheduler مقصد در دسترس نیست. بنابراین نمودارها و شمارنده‌ها با دیتابیس واقعی Staging در این محیط مشاهده/تطبیق نشده‌اند. اجرای سناریوهای قطع DB، تطبیق Queryهای مرجع، نقش‌های واقعی، ACL، ساخت ZIP Agent و Backup/Restore همچنان طبق راهنمای فاز ششم الزامی است.

این الحاقیه کدنویسی داشبورد را تکمیل می‌کند؛ به‌تنهایی گواه پذیرش عملیاتی فاز ششم یا مجوز نصب Production نیست.


در نسخهٔ 1.62.73، آمار Spool از Cache پنج‌ثانیه‌ای با invalidation هنگام نوشتن و بازپخش استفاده می‌کند؛ این کار بار اسکن کامل صف را در بازدیدهای پرتکرار داشبورد کاهش می‌دهد.
