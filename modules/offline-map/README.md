# ماژول نقشهٔ آفلاین ایران

ماژول مستقل و متصل به پوسته، نشست، پایگاه‌داده، منو و مجوزهای سامانه.

## وضعیت فعلی

- ورودی مستقل: `offline-map.php`
- نمایش داخل پوستهٔ اصلی سامانه با همان نشست و مجوزها
- API داخلی برای فهرست، ثبت و حذف نقاط
- ذخیرهٔ عوارض کاربر در جدول مستقل `offline_map_features`
- نمایش نقاط ذخیره‌شده روی نقشه، در صورت نصب کتابخانه‌ها و بستهٔ دادهٔ محلی
- عدم استفاده از CDN، tile server یا geocoder بیرونی در زمان اجرا
- اگر داده یا کتابخانهٔ محلی موجود نباشد، صفحه وضعیت نصب‌نبودن را اعلام می‌کند و نقشهٔ اینترنتی جایگزین نمی‌کند.
- اسکریپت محلی ساخت PMTiles از PBF در `tools/Build-OfflineIranMap.ps1` و کنترل یکپارچگی بسته در `tools/Test-OfflineIranMapPackage.ps1` قرار دارد؛ راهنما در `tools/README-FA.md` است.

## نصب ساختار داده

برای نصب تازه، `schema.sql` و `install-empty-db.sql` جدول و baseline را می‌سازند. برای ارتقای پایگاه‌دادهٔ موجود، پس از تهیهٔ نسخهٔ پشتیبان، فایل زیر را یک‌بار اجرا کنید:

`migrations/038-offline-map-features.sql`

## مجوزها

- `map.view`: مشاهدهٔ ماژول
- `map.features.manage`: ثبت و مدیریت عوارض متعلق به خود کاربر
- `map.admin`: مدیریت عوارض همهٔ کاربران

مجوزها به کاتالوگ نقش‌های سامانه افزوده شده‌اند. دسترسی مشاهده به نقش‌های عملیاتی پیش‌فرض داده شده؛ مدیریت عوارض نیز به نقش‌های عملیاتی کارکنان افزوده شده است. ادمین اصلی دسترسی کامل دارد. تنظیمات سفارشی نقش‌ها طبق سازوکار فعلی سامانه محترم می‌ماند.

## نصب دارایی‌های محلی نقشه

دارایی‌های زیر باید در استقرار آفلاین و با نسخه‌های ثابت و دارای مجوز مناسب قرار بگیرند:

- `vendor/maplibre-gl.js`
- `vendor/maplibre-gl.css`
- `vendor/pmtiles.js`
- `data/iran.pmtiles`
- `data/style.json` و تمام sprite/fontهای ارجاع‌شده از آن

سبک نقشه باید فقط از source، glyph، sprite و URLهای محلی استفاده کند. منبع PMTiles در style باید به فایل محلی اشاره کند. پیش از تحویل، manifest و checksum و مجوز منبع داده باید همراه بسته ارائه شود.

**محدودیت مهم:** دادهٔ پایهٔ ایران و فایل‌های کتابخانه هنوز در این شاخه قرار نگرفته‌اند. اسکریپت ساخت، فقط PMTiles را از PBF تولید می‌کند؛ استایل محلی، glyph/sprite، شاخص جست‌وجوی فارسی و مرزهای رسمی هنوز باید تهیه و اعتبارسنجی شوند. بنابراین نمایش نقشهٔ پایه و جست‌وجوی سراسری خیابان/کوچه هنوز فعال نیست. ثبت نقاط فعلاً از طریق مختصات اعشاری انجام می‌شود؛ ابزار ترسیم خط/چندضلعی و پیوست نیز هنوز پیاده‌سازی نشده‌اند.

## کنترل کیفیت شاخه

آزمون اختصاصی ماژول با GitHub Actions اجرا می‌شود: lint فایل‌های PHP، بررسی نحو JavaScript، قراردادهای ایستای دسترسی/آفلاین و هم‌ترازی baseline نصب تازه. نتیجهٔ آزمون‌های این شاخه باید پیش از ادغام جداگانه بازبینی شود.
