# ماژول نقشه ملی آفلاین

این ماژول به‌صورت مستقل در سامانه م توسعه می‌یابد. جزئیات معماری، منابع داده، الزامات مجوز و معیارهای پذیرش در `docs/OFFLINE-GIS-ARCHITECTURE-FA.md` ثبت شده است.

## اصول غیرقابل‌مذاکره

- هیچ تغییری در `main` انجام نمی‌شود؛ تمام توسعه فقط روی شاخه `feature/offline-national-gis-map` است.
- نقشه در زمان اجرا کاملاً آفلاین است؛ CDN، tile server عمومی، geocoder عمومی و فونت راه دور ممنوع‌اند.
- داده پایه و عوارض اختصاصی دو حوزه مستقل‌اند.
- هیچ ادعای پوشش کامل کوچه/ساختمان/پلاک بدون بررسی داده واقعی پذیرفته نیست.
- بسته نقشه باید نسخه، منبع، مجوز، تاریخ استخراج و SHA-256 داشته باشد.
- مهاجرت دیتابیس باید افزایشی و قابل بازگشت باشد و نصب تازه نیز در نظر گرفته شود.

## وضعیت

در این مرحله فقط مستند معماری و دامنه تثبیت شده است. صفحه عملیاتی نقشه تا زمان آماده‌سازی و میزبانی محلی کتابخانه‌ها و داده‌های برداری نباید به‌عنوان نقشه آماده استفاده معرفی شود.
