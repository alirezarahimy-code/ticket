# گزارش اصلاح فوری Ticket 1.61.10 — پنل مدیریت غذا (R32)

**پایه:** بستهٔ R31 · **تاریخ:** ۲۰۲۶/۱۰/۲۴

**مهاجرت دیتابیس:** ندارد

## علت مشکل پس از نصب R31

بررسی خود ZIP تحویل‌شدهٔ R31 نشان داد بسته، `food-ticket-web/index.html` و handler سمت سرور را داشت، اما هیچ‌کدام از فایل‌های `food-ticket-web/assets/` را در بر نمی‌گرفت؛ درحالی‌که صفحه آن‌ها را برای رابط مدیریت غذا بارگذاری می‌کند. بنابراین نصب R31 می‌توانست صفحه/handler جدید را کنار JavaScript و CSS قدیمی یا فایل دستیِ غایب قرار دهد. نتیجه می‌تواند بارگذاری‌نشدن ثبت دستی و نمایش‌ندادن عملیات گروهی و امکانات مدیریت غذا باشد.

## اصلاح این بسته

- فایل‌های رابط غذاییِ لازم، از جمله `food-manual-attendance.js`، `food-groups.js` و `food-menu.js`، همراه CSSهای متناظر اضافه شده‌اند.
- نسخهٔ query string دارایی‌های تغییریافته در `food-ticket-web/index.html` افزایش یافته تا مرورگر نسخهٔ cacheشدهٔ قبلی را به‌کار نبرد.
- handler غذایی `food-ticket.php` نیز در بسته است تا مسیرهای API دستی و گروهی هم‌نسخه باشند.
- بسته فقط شامل فایل‌های سامانهٔ غذاست؛ هیچ فایل ticket عمومی، CD/DVD یا inventory در آن نیست.

## بررسی‌ها

- Python food static tests: **۸۰ موفق و ۱۸ زیربررسی موفق**.
- آزمون تقویم غذا و آزمون گروه‌بندی منو: **موفق**.
- `node --check` برای JavaScriptهای پنل غذا: **موفق**.
- بررسی وجود فایل‌های موردنیاز صفحه و مسیرهای ثبت دستی/گروهی در handler: **موفق**.
- آزمون دیتابیسی تازه روی نصب مشتری اجرا نشده است؛ این بسته UI و cache busting را ترمیم می‌کند و migration لازم ندارد.

## نصب

1. از فایل‌ها و پایگاه‌داده نسخهٔ پشتیبان بگیرید.
2. ZIP را باز کنید و محتویات `files/` را روی ریشهٔ برنامه کپی کنید و فایل‌های هم‌نام را جایگزین کنید.
3. مرورگر را با بارگذاری اجباری تازه کنید (Ctrl+F5) یا کش سایت را پاک کنید.
4. در مدیریت غذا، ثبت دستی، گروه‌ها و عملیات گروهی را بررسی کنید.
