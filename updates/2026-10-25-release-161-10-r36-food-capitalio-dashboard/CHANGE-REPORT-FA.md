# گزارش تغییرات R36 — داشبورد غذا بر پایهٔ پیش‌نمایش صحیح ۴۱۷۹

**تاریخ:** ۱۴۰۵/۰۸/۰۳ (۲۰۲۶/۱۰/۲۵)  
**نسخهٔ سامانه:** ۱.۶۱.۱۰  
**مبنای بصری و پیاده‌سازی:** `Food Dashboard Preview:4179`

## تغییرات

- صفحهٔ داشبورد از همان کامپوننت‌های React و پوستهٔ واقعی پیش‌نمایش ۴۱۷۹ ساخته شده است؛ بازسازی جداگانه با HTML/CSS به‌عنوان مرجع استفاده نشده است.
- سایدبار تکراری ایجاد نشده و ناوبری بومی پنل غذا و تب‌های اصلی آن حفظ می‌شود.
- داده‌ها از loader محلی موجود پنل و APIهای همان ماژول دریافت می‌شوند؛ نمودارها، کارت‌ها، وضعیت امروز، نتایج و رویدادها با دادهٔ جاری محصول پر می‌شوند. اگر منبع در دسترس نباشد، مقدار ناموجود با خط تیره/پیام انتظار مشخص می‌شود.
- داده‌ها و fixtureهای پیش‌نمایش وارد bundle محصول نشده‌اند. bundle شامل فقط runtime داشبورد است؛ بررسی رشته‌های نمونهٔ شناخته‌شده در خروجی build موردی پیدا نکرد.
- CSS داشبورد زیر ریشهٔ اختصاصی کامپوننت محدود شده و CSS مربوط به سایدبار پیش‌نمایش حذف شده است تا به منوها و سایر صفحات محصول نشت نکند.
- JavaScript، CSS و فونت‌های لازم محلی و داخل بسته قرار دارند؛ وابستگی به CDN، سرویس ابری یا اینترنت زمان اجرا وجود ندارد.
- رنگ‌های چهار سری نمودار و شاخص‌های وضعیت مطابق مقادیر خود preview 4179 تنظیم شده‌اند: سبز `#008A45`، قرمز `#D7263D`، آبی `#1D4ED8` و نارنجی `#F08A00`.
- این تغییر فقط رابط داشبورد/مدیریت غذا را هدف می‌گیرد و مهاجرت پایگاه‌داده ندارد.

## فایل‌های بسته

- `food-ticket-web/index.html`
- `food-ticket-web/assets/food-capitalio-dashboard-4179.js`
- `food-ticket-web/assets/food-capitalio-dashboard-4179.css`
- سه فونت محلی Vazirmatn موردنیاز CSS داشبورد
- manifest و همین گزارش تغییرات

## نصب

1. پیش از نصب از فایل‌ها و پایگاه‌داده نسخهٔ پشتیبان بگیرید.
2. ZIP را از صفحهٔ «به‌روزرسانی و پشتیبان‌گیری» بارگذاری کنید.
3. پس از نصب، پنل غذا را با `Ctrl+F5` تازه کنید.

## اعتبارسنجی انجام‌شده

- TypeScript با `npx tsc -p tsconfig.app.json --noEmit` بررسی شد.
- build تولیدی bundle داشبورد با Vite موفق بود.
- `node --check` روی اسکریپت inline صفحهٔ محصول و bundle داشبورد موفق بود.
- بررسی CSS تأیید کرد همهٔ selectorها زیر ریشهٔ داشبورد scope شده‌اند و selectorهای تغییر سایدبار preview در bundle نیستند.
- جست‌وجوی bundle برای fixtureها و متن/مقادیر نمونهٔ شناخته‌شده نتیجه‌ای نداشت.
- در گزارش نهایی، آزمون‌های انجام‌شده از موارد انجام‌نشده جدا می‌شوند؛ preview صحیح ۴۱۷۹ حفظ می‌شود.

## انجام‌نشده / محدودیت

- PHP CLI در محیط موجود نبود؛ `php -l` اجرا نشد.
- آزمون مرورگر headless و مقایسهٔ screenshot خودکار اجرا نشد.
- آزمون‌های حوزهٔ تیکت، CD/DVD و inventory اجرا نشدند؛ این بسته فقط به داشبورد/مدیریت غذا مربوط است.
