## محل استقرار

گزارش **داخل منوی «سامانه مدیریت غذا ← گزارشها»** قرار میگیرد: به `REPORT_TABS` همان صفحه
تب **«غایبین ناهار»** اضافه شده است. **هیچ نمای مستقل / آیتم ناوبری تازهای** ساخته نشده؛
مجوز همان `'reports' => food.reports` است. گزینهٔ قدیمی «نوع گزارش = غایبین» از فرم
گزارشگیری حذف شد و حالت ذخیرهشدهٔ کاربران به تب تازه هدایت میشود.
دو صفحه **کاملاً جدا**اند: پنج چیپ آمار فقط داخل فرم «گزارشگیری»؛ سه چیپ
(مجموع پرس / افراد یکتا / معاونتها) فقط داخل فرم «غایبین ناهار»، بعد از «امروز».

ردیفها: «فهرست یکجا» و «بر اساس معاونت» = یک ردیف بهازای هر فرد (`تعداد غیبت`)؛
«تفکیک و جزئیات» = یک ردیف بهازای هر غیبت، پس اعضای چندغیبته تکرار میشوند.
فیلدها بهازای هر تب جداگانه ذخیره میشوند تا دستکاری یک تب، تب دیگر را خراب نکند.

## قواعد رعایتشده

- لیست **۱۰۰٪ عرض صفحه** (`table-layout:fixed` + درصد ستونها)؛ «بلوک در هر ردیف» ۱/۲/۳ ستونها را ضرب میکند.
- خروجی **XLSX واقعی** از همان action رسمی `index.php?action=export_view_xlsx` (نه CSV).
- چاپ خالص با `@media print` و بدون دستکاری DOM نمایشی؛ سایر گزارشها دستنخوردهاند.
- چارت بدون CDN و بدون کتابخانه؛ فقط توکنهای تم اصلی (`--teal`, `--navy-2`, `--gold`, `--teal-light`, …) و CSS/SVG-free.
- بدون `DROP` / `DELETE` / مهاجرت؛ بدون تغییر شاخه، بدون استقرار production، بدون لینکدادن به `downloads/index.html`.
