# ترمیم فایل‌های نسخهٔ ۱.۶۲.۳۶

این بسته برای وضعیتی است که بستهٔ اصلی ۱.۶۲.۳۶ نصب شده، اما بخش‌هایی مانند داشبورد/پنل یا فرم ثبت دستی غذا به‌دلیل ناقص‌بودن فهرست فایل‌های آن بسته برنگشته‌اند.

- نسخهٔ بسته و فایل `VERSION`: **۱.۶۲.۳۶**؛ برای نصب مجدد همان نسخه.
- پایگاه داده: بدون migration و بدون تغییر.
- فایل‌ها: نسخه‌های پیش از تغییرات ۱.۶۲.۳۷، از جمله `index.php`، پنل وب غذا و فایل‌های لازم برای ثبت دستی.
- updater موجود در سامانه نصب مجدد همان نسخه را می‌پذیرد؛ این بسته باید روی نسخهٔ نصب‌شدهٔ ۱.۶۲.۳۶ اعمال شود.

پیش از نصب، از فایل‌های سرور backup بگیرید و فایل‌های اختصاصی خود را بررسی کنید؛ فایل‌های فهرست‌شده کامل جایگزین می‌شوند. این بسته از اینجا روی سرور زنده نصب نشده است.
