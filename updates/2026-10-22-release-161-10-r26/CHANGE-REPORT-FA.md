# گزارش اصلاحیهٔ Ticket 1.61.10 — بستهٔ R26

**تاریخ:** ۲۰۲۶/۱۰/۲۲
**پایه:** R25
**مهاجرت دیتابیس:** ندارد

## بازگردانی استخراج محلی سخت‌افزار

1. دکمهٔ «استخراج محلی همین سیستم» در فهرست دارایی‌ها و صفحهٔ جزئیات دارایی‌های محلی در دسترس است.
2. استخراج محلی اطلاعات میزبان اجرای PHP/وب‌سرور را جمع می‌کند؛ اگر مرورگر فقط به یک سرور مرکزی وصل شده باشد، اطلاعات سخت‌افزار خود مرورگر خوانده نمی‌شود.
3. اگر جمع‌آوری ناموفق باشد یا امتیاز اطلاعات سخت‌افزاری صفر باشد، دارایی خالی در پایگاه داده ثبت/به‌روزرسانی نمی‌شود و پیام خطا به کاربر برمی‌گردد. در موفقیت، پیام نتیجه نیز پس از پایان جمع‌آوری نمایش داده می‌شود.
4. گزارش‌های تشخیصی و API موجود برای بررسی جمع‌آوری به‌روز شده‌اند.

## اسکن شبکه و ایمنی اعتبارنامه

اعتبارنامهٔ Domain Admin فقط برای اجرای همان اسکن در نشست کاربر به‌صورت رمز‌شدهٔ موقت نگه داشته می‌شود و در پایگاه داده ذخیرهٔ دائمی نمی‌شود. فرم اجرای اسکن HTTPS می‌خواهد. برای دسترسی به حدود ۱۵۰ رایانه نیازی به ساخت حساب ادمین محلی جداگانه نیست؛ امکان دسترسی شبکه باید با سیاست‌های دامنه و مجوزهای سامانهٔ مقصد فراهم باشد.

## آزمون و دامنهٔ تأیید

- ۶ آزمون ایستا و متمرکز موجودی سخت‌افزار موفق شدند.
- بررسی نحوی PHP برای فایل‌های تغییریافته و `node --check assets/app.js` موفق بود؛ `git diff --check` نیز خطایی نداشت.
- اجرای واقعی روی Windows/WMI یا آزمون در پنجرهٔ مرورگر این بسته انجام نشده است؛ نصب آزمایشی روی میزبان موردنظر لازم است.
- هیچ استقرار تولیدی، تغییر دادهٔ تولیدی یا migration دیتابیس انجام نشده است.
