# بازبینی دوم بستهٔ ۱.۶۲.۷۳

این بسته از updater cumulative منتشرشدهٔ ۱.۶۲.۷۳ ساخته شده و فایل داشبورد را با نسخهٔ اصلاح‌شده جایگزین می‌کند. مقدار برنامه عمداً همان `1.62.73` است؛ updater نصب مجدد همان نسخه را مجاز می‌داند. مهاجرت جدیدی اضافه نشده است؛ فهرست ۰۲۰ و ۰۲۱ برای ارتقای cumulative از نسخه‌های قبلی حفظ شده و در نصب ۱.۶۲.۷۳ پس از ثبت‌شدن، دوباره اجرا نمی‌شود.

بستهٔ تازه فقط پاک‌سازی داشبورد را اضافه می‌کند؛ جزئیات فیش خودکار و سفارش در گزارش‌ها می‌مانند. لاگینگ آزمایشی ۱.۶۲.۷۱ داخل این بسته نیست.
