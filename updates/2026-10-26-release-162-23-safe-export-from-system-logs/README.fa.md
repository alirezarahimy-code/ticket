# نسخهٔ تجمعی ۱.۶۲.۲۳ — دکمهٔ خروجی امن در لاگ سامانه

این بسته برای نصب روی ۱.۶۲.۲۲ یا بالاتر است و شامل تغییرات تجمعی قبلی نیز هست. دکمهٔ «دانلود گزارش فنی پالایش‌شده برای پشتیبانی» در صفحهٔ «لاگ سامانه» کنار ابزارهای همان صفحه نمایش داده می‌شود؛ فقط کاربران دارای مجوز `system.health` آن را می‌بینند. دکمه مسیر خروجی امن سلامت سامانه را باز می‌کند.

مهاجرت جدیدی ندارد.
