# گزارش تغییرات R34 — داشبورد مدیریت غذا

**تاریخ:** ۱۴۰۵/۰۸/۰۳ (۲۰۲۶/۱۰/۲۵)  
**نسخهٔ سامانه:** ۱.۶۱.۱۰ (بستهٔ ترمیمی همان نسخه)  
**مبنای بسته:** R33.1

## تغییرات

- طراحی داشبورد در همان `dashboardView()` ماژول غذا ادغام شد؛ iframe و bundle مستقل پیش‌نمایش در محصول نیست.
- آمار از APIهای محلی خود ماژول دریافت می‌شود: سفارش فعال غذا در بازهٔ هفت‌روزه، مانیتورینگ تردد/چاپ همان بازه، و فهرست کارکنان از API موجود. هیچ عدد نمونه یا دادهٔ preview برای نمایش استفاده نمی‌شود.
- چهار کارت بالای داشبورد هرکدام یک مقدار روز، تغییر نسبت به روز قبل و sparkline هفت‌روزه دارند؛ چهار شاخص از سفارش، مانیتورینگ/تردد، چاپ موفق و نیازمند پیگیری محاسبه می‌شوند. شمار کارکنان فعال در سربرگ می‌آید.
- چهار سری نمودار از دادهٔ واقعی ساخته می‌شوند: سفارش غذا، تردد ثبت‌شده، فیش چاپ‌شده و رویدادهای نیازمند پیگیری. رنگ‌ها سبز `#008A45`، قرمز `#D7263D`، آبی `#1D4ED8` و نارنجی `#F08A00` هستند؛ ناحیهٔ زیر خطوط گرادیان محوشونده و دو سری خط‌چین متمایز دارند.
- نشانگرهای نمودار با ماوس و صفحه‌کلید tooltip تاریخ/سری/مقدار نشان می‌دهند؛ کارت‌ها هنگام hover بالا می‌آیند و سایه/حاشیه می‌گیرند. ورود کارت‌ها، sparklineها، نمودار و حلقه نیز انیمیشن دارند.
- نمودار حلقه‌ای وضعیت فیش‌های امروز را از رویدادهای واقعی نشان می‌دهد. وقتی تعداد همهٔ وضعیت‌ها صفر باشد، مرکز عدد صفر را نشان می‌دهد و چهار قطعهٔ رنگی فقط برای راهنمای دسته‌ها باقی می‌مانند.
- دکمهٔ پوستهٔ روشن/تیره با افکت گسترش دایره‌ای حدود دوثانیه‌ای در مرورگرهای پشتیبان View Transition کار می‌کند؛ fallback CSS هم در مرورگرهای دیگر انیمیشن را اجرا می‌کند.
- ارتباط فقط با API محلی ماژول است و وابستگی اینترنتی یا تغییر پایگاه‌داده ندارد. داده‌ها هنگام دسترس‌نبودن API به‌صورت خط تیره نمایش داده می‌شوند، نه صفر ساختگی.
- نسخهٔ پنل به `1.37.19` افزایش یافت تا نسخهٔ فایل با نسخهٔ مورد انتظار PHP هماهنگ باشد.

## نصب

1. پیش از نصب، از فایل‌ها و پایگاه‌داده نسخهٔ پشتیبان بگیرید.
2. فایل ZIP را از صفحهٔ «به‌روزرسانی و پشتیبان‌گیری» بارگذاری کنید. مهاجرت پایگاه‌داده‌ای ندارد.
3. پس از نصب، با `Ctrl+F5` صفحهٔ مدیریت غذا را تازه کنید.

## اعتبارسنجی انجام‌شده

- build محلی Vite، TypeScript و ESLint روی منبع مرجع طراحی موفق بود؛ bundle پیش‌نمایش در محصول یا بستهٔ آپدیت قرار نگرفت.
- بررسی مستقیم بستهٔ R34، مسیرهای API محلی، پالت نمودار، ساختار SVG و محدودبودن فایل‌های بسته به ماژول غذا انجام شد.
- renderer داشبورد با fixture آزمایشیِ هم‌شکل پاسخ API بررسی شد؛ عددها از state ورودی محاسبه شدند و منبع ناموجود به‌جای عدد/برش ساختگی، خط تیره و حلقهٔ خنثی نشان داد.
- بررسی نحوی JavaScript، parse شدن CSS و `git diff --check` موفق بود.

## انجام‌نشده / محدودیت محیط

- اجرای `pytest` ممکن نبود؛ این محیط ماژول/فرمان pytest ندارد. اعتبارسنجی اختصاصی بسته به‌صورت مستقیم با Python اجرا شد.
- `php -l` ممکن نبود؛ PHP CLI در این محیط نصب نیست.
- آزمون واقعی مرورگر و تعامل بصری با API/پایگاه‌دادهٔ محلی انجام نشد.
- آزمون‌های تیکت، CD/DVD و شناسنامه/انبار اجرا نشده‌اند؛ این بسته فقط برای داشبورد مدیریت غذاست.
