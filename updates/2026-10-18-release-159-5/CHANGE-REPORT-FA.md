## مرحلهٔ ۰ب در این محیط

روی sandbox این نشست `php` / `piper` / `espeak-ng` و فایل `.onnx.json` نصب‌شدهٔ سرور شما وجود نداشت؛ بنابراین **IPA زنده و wav آزمایشگاه اینجا ثبت نشد.** آزمایشگاه در مدیریت آریا برای اجرای ماتریس الف–ز روی سرور ویندوز آماده است.

| فرض | وضعیت | شاهد |
|---|---|---|
| ا) JSON نصب‌شده = GitHub | **نامشخص** | فایل محلی نبود. آزمایشگاه sha256 و `phoneme_type`/`voice`/`sample_rate`/تعداد کلید را با نسخهٔ GitHub مقایسه می‌کند. |
| ب) دادهٔ eSpeak داخل Piper = espeak-ng.exe | **نامشخص** | `--path` به `espeak-ng-data` کنار piper در آزمایشگاه هست. |
| ج) ZWNJ مرز واژه است | **موقت تأیید از fa_rules** نه IPA زنده | سیاست تولید: **حفظ نیم‌فاصله**. قابل تغییر با تنظیم `chatbot_tts_zwnj`. |
| د) اعراب کامل داخل واژه | **انتخاب‌نشده** | قاعدهٔ همگانی «سَ» حذف شد. حرکت فقط از واژه‌نامه. مسیر «و» فقط در آزمایشگاه. |
| ه) علت سکون = نبود مصوت کوتاه | **حدس، بدون شاهد صوتی** | واژه‌نامه برای واژه‌های دامنه؛ بقیه بدون حرکت همگانی. |

**دروازهٔ تصمیم (موقت، تا ۰ب روی سرور شما):** واژه‌نامهٔ املایی + حرکت انتخابی برای چند واژهٔ پرکاربرد (`سلام`→`سَلام`). نیم‌فاصله حفظ. «هٔ»→`ه‌یِ`. `[[واج]]` اگر در واژه‌نامه باشد عبور می‌کند و کسره رویش نمی‌آید.

## این نسخه نسبت به ۱.۵۹.۴

- خط لولهٔ `chatbot_tts_prepare`: نیم‌فاصله/اعراب/«هٔ» در `clean` به فاصله تبدیل نمی‌شوند.
- کسرهٔ اضافه با فهرست رد فعل/را/رو؛ مختوم به ا/و → «یِ»، ه → «ه‌یِ»، ی → «ِ».
- قاعدهٔ همگانی «س ← سَ» حذف شد.
- اعداد، تاریخ جلالی ۱۳/۱۴xx، ساعت، تلفن رقم‌به‌رقم، مخفف‌های IT، پیوند، مارک‌داون.
- محاوره پیش‌فرض خاموش؛ `length_scale` بین ۱٫۰ و ۱٫۱.
- واژه‌نامه `chatbot-tts-lexicon.php` (روی سرور می‌توان `storage/tts/lexicon.php` را overlay کرد).
- متن گفتاری دست‌نویس FAQ در `storage/tts/spoken.json` (بدون مهاجرت).
- آزمایشگاه تلفظ در مدیریت آریا.
- کش صدا شامل نسخهٔ قواعد و هش واژه‌نامه است.
- اصلاحات UI غذای قبلی (۴ستون، تیک قبل از نام، سقف مهمان، رفرش تب) در همین بسته است.

## نصب

1. از سامانه نسخهٔ پشتیبان بگیرید.
