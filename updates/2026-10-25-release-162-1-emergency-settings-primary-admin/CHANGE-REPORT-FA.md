# گزارش تغییرات بستهٔ مستقل 1.62.1

## اصلاح محل و مجوز ثبت اضطراری غذا
- فرم «ثبت اضطراری سفارش غذا» از تقویم/برنامهٔ روزانهٔ پنل غذا برداشته شد.
- فرم اکنون در **تنظیمات سیستم ← ثبت اضطراری سفارش غذا** قرار دارد و در فهرست زیرفرم‌ها بلافاصله بعد از **ثبت دستی فیش** می‌آید.
- این زیرفرم فقط برای ادمین اصلی نمایش داده می‌شود. endpointهای بررسی وضعیت، فعال‌سازی و لغو نیز در route و توابع دامنه فقط ادمین اصلی را می‌پذیرند؛ مدیر پشتیبانی حتی با فراخوانی مستقیم API دسترسی ندارد.
- مهلت همچنان محدود به روز/وعدهٔ معین، یک تا ۲۴ ساعت و همراه دلیل auditشده است؛ ساختار دیتابیس تغییر نکرده است.

## قابلیت‌های مستقل 1.62
- گزارش Excel سفارش‌های فعال کارکنان انتخاب‌شده در بازهٔ تاریخ شمسی و وعده.
- تفکیک حوزهٔ دسترسی تیکت‌های پشتیبانی و IT؛ مدیر پشتیبانی به تیکت IT دسترسی ندارد.

## نصب و بررسی
- این ZIP شامل manifest و فایل‌های اجرایی لازم همین قابلیت‌هاست و migration ندارد؛ نسخهٔ قبلی و بسته‌های R34 تا R43 حذف یا بازنویسی نشده‌اند.
- آزمون static غذا (۳۷ مورد)، آزمون JavaScript پنل غذا، بررسی نحوی JavaScript و parse نحوی PHP فایل‌های غذا موفق شدند. آزمون‌های تیکت، CD/DVD و inventory عمداً اجرا نشدند.
- PHP/MySQL runtime و محیط واقعی سامانه در دسترس نبود؛ نتیجهٔ runtime یا production ادعا نمی‌شود.
