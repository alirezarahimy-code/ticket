# گزارش تغییرات بستهٔ مستقل 1.62.0

## قابلیت‌های سفارش غذا
- مسیر مهلت اضطراری در پنل مدیریت غذا مشخص است: **مدیریت غذا ← برنامهٔ غذایی ← انتخاب روز و وعده ← بخش «مهلت استثنایی ثبت سفارش» زیر برنامهٔ همان روز**. مدیر مجاز، تاریخ و وعدهٔ محدود را انتخاب می‌کند؛ مهلت سراسری یا دائمی ایجاد نمی‌شود.
- در بخش آمار، حالت «سفارش کارکنان انتخاب‌شده» اضافه شده است. مدیر می‌تواند کارکنان را جست‌وجو و انتخاب/حذف کند، بازهٔ تاریخ شمسی و وعده را تغییر دهد و جزئیات سفارش‌های فعال افراد انتخاب‌شده را به Excel خروجی بگیرد.
- جست‌وجوی عمومی کارکنان شمارهٔ پرسنلی را افشا نمی‌کند؛ lookup شمارهٔ پرسنلی برای گزارش مدیر به endpoint جداگانه و دارای مجوز محدود شده است.

## تفکیک دسترسی تیکت
- مدیر پشتیبانی در سطح SQL به گروه پشتیبانی محدود می‌ماند؛ دسترسی مشاهدهٔ جزئیات/اقدام روی تیکت نیز با گروه خدمت کاربر تطبیق داده می‌شود تا تیکت‌های IT از نقش پشتیبانی قابل دسترسی نباشند.
- بسته فقط فایل‌های مرتبط را جایگزین می‌کند؛ داده‌ها و ساختارهای قبلی/ماژول‌های دیگر دست‌نخورده می‌مانند.

## نصب و بررسی
- فایل ZIP شامل manifest، همین گزارش، فایل‌های لازم و آزمون static مرتبط با سفارش غذا نیست؛ migration پایگاه‌داده ندارد.
- روی نسخهٔ پشتیبان نصب و سپس کنترل دسترسی نقش‌های پشتیبانی/IT را با حساب‌های متناظر بررسی کنید. آزمون runtime با PHP/MySQL در این محیط در دسترس نبود.
- آزمون‌های static غذا، تست JavaScript مرتبط، بررسی نحوی JavaScript و parse نحوی چهار فایل PHP تغییرکرده با موفقیت اجرا شدند. تست‌های تیکت، CD/DVD و inventory عمداً اجرا نشدند.

> این بسته رفع رخداد سقف مهمان را ادعا نمی‌کند؛ تشخیص آن همچنان نیازمند دادهٔ runtime همان سامانه است.
