# نسخهٔ ۱.۶۲.۲۸ — به‌روزرسانی فرم شناسنامه‌های فنی

**حداقل نسخهٔ پایه:** ۱.۶۲.۲۵ (روی ۱.۶۲.۲۶ و ۱.۶۲.۲۷ نیز قابل نصب است)  
**فایل‌های اصلی:** `asset-profile.php`، `asset-inventory-page.php`، `index.php` و `assets/style.css`  
**مهاجرت SQL جداگانه:** ندارد

## چه چیزی به‌روزرسانی می‌شود؟

- تعریف و رندر ۷۴ فیلد شناسنامه در ۹ بخش، همراه با ذخیرهٔ فرم و همگام‌سازی فیلدهای اصلی دارایی.
- استایل فرم و فهرست با همان خانوادهٔ CSS نسخهٔ ۱.۶۲.۲۴، به‌علاوهٔ تغییر شناسهٔ cache برای دریافت نسخهٔ تازهٔ stylesheet.
- `index.php` ماژولار سازگار با شاخهٔ ۱.۶۲.۲۴ حفظ می‌شود؛ فایل monolithic قدیمی جایگزین آن نمی‌شود.
- سازگاری فراخوانی‌های قدیمی و جدید رندر فهرست شناسنامه نیز همراه بسته است.

`asset_profile_ensure_schema()` در بازکردن فرم، جدول/ستون‌های لازم را به‌صورت افزایشی بررسی و در صورت نبود اضافه می‌کند؛ دادهٔ موجود را حذف یا بازنویسی نمی‌کند. با وجود افزایشی‌بودن کار، پیش از نصب از فایل‌ها و پایگاه‌داده بکاپ بگیرید.

## نصب و بررسی

1. این بسته برای نسخهٔ ۱.۶۲.۲۵ یا بالاتر تا ۱.۶۲.۲۷ است؛ روی نسخهٔ بالاتر از ۱.۶۲.۲۸ downgrade نکنید.
2. از پایگاه‌داده و فایل‌ها پشتیبان مستقل تهیه کنید.
3. ZIP را از بخش به‌روزرسانی خود سامانه بارگذاری کنید؛ دستی extract نکنید.
4. صفحهٔ فهرست شناسنامه‌ها را باز کنید، یک سیستم را انتخاب کنید، همهٔ بخش‌های فرم را ببینید، یک فیلد بی‌خطر را ذخیره و صفحه را تازه‌سازی کنید تا ماندگاری آن را تأیید کنید.
5. اگر فرم یا ذخیره‌سازی مشکل داشت، فایل‌های این بسته را از بکاپ قبلی برگردانید و پیش از ادامه جزئیات خطای سرور را بررسی کنید.

بسته از نظر manifest، مسیرها و ZIP بررسی ایستا شده است؛ روی سرور واقعی اجرا نشده و نصب آن تضمین‌شده فرض نمی‌شود.
