# راهنمای بستهٔ تجمیعی ۱.۶۲.۵۶

- بستهٔ تجمیعی شامل اصلاحات نسخه‌های **۱.۶۲.۴۸ تا ۱.۶۲.۵۶** است و روی پایهٔ **۱.۶۲.۴۷** اعمال می‌شود.
- از فایل‌ها و پایگاه‌داده پشتیبان تهیه کنید؛ ترجیحاً ابتدا روی staging یا clone بازیابی‌شده به‌روزرسانی را بررسی کنید.
- فایل ZIP را از مسیر رسمی **System Update** نصب کنید؛ migrationهای ۰۱۷ و ۰۱۸ را دستی یا هنگام بارگذاری صفحه اجرا نکنید.
- اگر بعضی نسخه‌های میانی قبلاً نصب شده‌اند، بسته همچنان فایل‌های نهایی را جایگزین می‌کند؛ برای اجرای migrationها فقط به وضعیت نمایش‌داده‌شده در System Update اعتماد کنید و از اجرای دستی مجدد خودداری کنید.
- V8 داخل این بسته نیست و نصب نمی‌شود.
- نام شرکت صرفاً عنوان نمایشی است. وضعیت شرکت از عضویت فعال در درخت محاسبه می‌شود؛ عضویت در شرکت نقش یا مجوز جداگانه‌ای ایجاد نمی‌کند.
- آزمون‌های ایستا، JavaScript و یکپارچگی ZIP موفق بودند. PHP runtime، مرورگر و DB آزمایشی در این محیط موجود نبودند.
