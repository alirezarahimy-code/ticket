# نسخهٔ ۱.۶۲.۳۰ — لغو شده؛ نصب نکنید

> این نسخهٔ اشتباه، فرم جدیدی در تنظیمات اصلی سامانه می‌ساخت و ماژول‌های فعال ۱.۶۲ را با فایل‌های قدیمی‌تر جایگزین می‌کرد. کاربر درست می‌گوید: ثبت دستی فیش از قبل در «سامانه مدیریت غذا ← تنظیمات ← ثبت دستی فیش» وجود داشت؛ باید همان قابلیت اصلاح می‌شد، نه اینکه فرم دیگری ساخته شود.

بستهٔ ۱.۶۲.۳۰ از فهرست دانلود شاخه حذف شده است. نسخهٔ اصلاح‌شدهٔ **۱.۶۲.۳۱** فرم موجود را به‌روز می‌کند و فایل‌های ماژولار را حفظ/بازمی‌گرداند. اگر ۱.۶۲.۳۰ نصب شده، به‌روزرسانی ۱.۶۲.۳۱ را اعمال کنید و سپس رفتار را طبق راهنمای نسخهٔ جدید بررسی کنید.
