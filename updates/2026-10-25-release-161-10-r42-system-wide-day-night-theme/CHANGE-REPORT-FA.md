# گزارش R42 — فعال‌سازی سراسری حالت روز و شب

**تاریخ:** ۱۴۰۵/۰۸/۰۳ (۲۰۲۶/۱۰/۲۵)  
**نسخهٔ سامانه:** ۱.۶۱.۱۰  
**دامنه:** پوستهٔ اصلی سامانه، صفحه‌های مستقل OLA/حاکمیت، و پنل مدیریت غذا

## رفتار

- دکمهٔ روز/شب در نوار بالایی سامانه قرار دارد و انتخاب را در cookie محلی مرورگر نگه می‌دارد؛ با رفتن به صفحه‌های دیگر سامانه، همان حالت ادامه می‌یابد. تنظیم رنگ تأکیدی فعلی (سبز/یاقوتی/لاجوردی/آجری) جداگانه حفظ شده است.
- CSS سراسری فقط کارت مرکزی را عوض نمی‌کند: پس‌زمینهٔ صفحه، هدر و منو، زیرمنوها، کارت‌ها، جدول‌ها، فرم‌ها، مودال‌ها، نمای سازمان، اعلان‌ها و footer نیز برای شب/روز تنظیم شده‌اند.
- پنل غذا همان حالت را از صفحهٔ میزبان می‌گیرد. اگر جداگانه اجرا شود، کنترل بالای خودش و ذخیره‌سازی محلی آن را به کار می‌اندازد. دکمهٔ قدیمی داخل بخش میانی داشبورد غذا پنهان شده تا دو کنترل ناسازگار دیده نشود.
- تغییر حالت با انتشار شعاعی از مرکز viewport انجام می‌شود؛ در مرورگرهای فاقد View Transition یا با `prefers-reduced-motion` تغییر بی‌انیمیشن به‌عنوان fallback است.
- هیچ وابستگی ابری، درخواست شبکهٔ بیرونی، دادهٔ نمونهٔ محصول یا migration پایگاه‌داده اضافه نشده است.

## آزمون‌های موفق

- `python3 tests/test_global_theme_mode.py` — assertionهای پوستهٔ اصلی، صفحات مستقل و میزبانی پنل غذا موفق.
- `node --check` برای `assets/app.js`، `food-brand.js` و bundle R42 — موفق.
- تجزیهٔ PHP با parser سازگار با PHP 8.2 برای فایل‌های تغییرکرده — موفق. این فقط syntax parse است، نه اجرای PHP روی سرور.
- ساخت Vite پیش‌نمایش بصری — موفق؛ تعامل سراسری دکمه در شبیه‌سازی DOM حالت `html` و `body` را هر دو به شب تغییر داد، برچسب/ARIA به‌روز شد و cookie نوشته شد.
- پیش‌نمایش پنل غذا همان toggle سراسری را اجرا کرد؛ CSSهای R42 با parser CSS بررسی شدند.
- ZIP با `unzip -t` بررسی و checksum محاسبه می‌شود.

## اجرا نشده / محدودیت

- PHP runtime در محیط موجود نیست؛ اجرای واقعی routeهای PHP یا اتصال به پایگاه‌داده انجام نشده است.
- نصب روی production/staging یا سرور Windows مشتری انجام نشده است.
- آزمون‌های تیکت، CD/DVD و inventory عمداً اجرا نشدند.
- تست تعاملی با مرورگر Chromium در این دور در دسترس نبود؛ پیش‌نمایش Vite و آزمون DOM به‌کار رفتند.
