# نسخهٔ ۱.۶۲.۲۲ — خروجی پالایش‌شدهٔ سلامت سامانه

این بستهٔ افزایشی برای نصب روی ۱.۶۲.۲۱ است و مهاجرت دیتابیس ندارد. دکمهٔ جدید در صفحهٔ سلامت سامانه گزارشی از خطاها و هشدارهای فنی تولید می‌کند. شناسه‌های کاربر، URL درخواست، یادداشت، متن خام خطا و متن کوئری از خروجی حذف شده‌اند؛ عنوان رخدادها به دستهٔ فنی تبدیل می‌شود.

این بسته علت هشدارهای ثبت‌شده یا مشکل صفحهٔ شناسنامه‌های فنی را رفع نمی‌کند؛ هدف آن استخراج گزارش پالایش‌شده برای تشخیص است.
