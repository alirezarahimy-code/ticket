# نسخهٔ تجمعی ۱.۶۲.۲۲ — خروجی پالایش‌شدهٔ سلامت سامانه

این بسته برای نصب روی نسخهٔ ۱.۶۲.۲۰ یا بالاتر ساخته شده و گزارش فیش‌های چاپ‌شدهٔ ۱.۶۲.۲۱ را نیز در خود دارد. پس از نصب، صفحهٔ «سلامت سامانه» دکمهٔ «دانلود گزارش فنی پالایش‌شده برای پشتیبانی» را نشان می‌دهد.

خروجی فقط خطاها و هشدارها را دارد؛ شناسهٔ کاربر، نشانی درخواست، یادداشت‌ها، متن خام خطا/کوئری و رویدادهای کاربران را صادر نمی‌کند. عنوان‌های آزاد به دسته‌های فنی تبدیل می‌شوند. مهاجرت جدیدی افزوده نشده؛ فایل‌های مهاجرت قبلی برای سازگاری بسته حفظ شده‌اند.

این اصلاح به‌تنهایی مشکل صفحهٔ شناسنامه‌های فنی را رفع نمی‌کند؛ خروجی امن لاگ را برای تشخیص فراهم می‌کند.
