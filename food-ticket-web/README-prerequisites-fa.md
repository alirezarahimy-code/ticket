# بستهٔ کامل پیش‌نیاز و اجرا

این پوشه برای اجرای برنامه روی Windows Server آماده شده است.

## محتویات

- `index.html`: پنل مستقل مدیریتی
- `FoodTicketServer.csproj` و `Program.cs`: سرویس .NET 8 برای Access/ODBC، پایش SOURCE_TABLE، ثبت مانیتورینگ، چاپ و Excel
- `config.example.json`: نمونهٔ تنظیمات
- `install_prerequisites.bat`: بررسی .NET 8، هشدار دربارهٔ Access ODBC و Restore بسته‌های پروژه
- `start_food_ticket.bat`: بررسی رمز مدیر و اجرای برنامه

## پیش‌نیازهای بیرونی

این موارد به‌دلیل قوانین توزیع Microsoft داخل ZIP قرار نمی‌گیرند:

- Windows 10/11 یا Windows Server
- .NET 8 SDK
- Microsoft Access Database Engine متناسب با معماری Windows
- دسترسی شبکه به فایل‌های `attendance.mdb` و دیتابیس سفارش
- نصب چاپگر شبکه روی همان Windows Server
- دسترسی نوشتن به مسیر گزارش‌ها

## نصب

1. کل ZIP را در یک مسیر ساده مثل `C:\FoodTicket` استخراج کنید.
2. `install_prerequisites.bat` را اجرا کنید. این فایل .NET 8 SDK را بررسی می‌کند، در صورت نبود تنظیمات فایل نمونه را کپی می‌کند و پروژه را Restore می‌کند.
3. اگر Access ODBC نصب نیست، Microsoft Access Database Engine متناسب با معماری Windows را نصب کنید و دوباره بررسی را اجرا کنید.
4. فایل `food_ticket_config.json` را از روی `config.example.json` بسازید یا اجازه دهید اسکریپت بسازد.
5. برای دست‌کم یک مدیر رمز غیرخالی بگذارید؛ سپس مسیر فایل منبع تردد، مسیر جدول سفارش، نام جدول‌ها، ستون‌ها، نام چاپگر نصب‌شده و مسیر گزارش را تکمیل کنید.
6. `start_food_ticket.bat` را اجرا کنید. سرویس به‌صورت پیش‌فرض فقط روی `http://127.0.0.1:8080` گوش می‌دهد.
7. پنل را روی همان سرور با آدرس `http://127.0.0.1:8080/index.html` باز کنید.
8. در حالت یکپارچه، سرویس فایل `food_ticket_config.json` را از پوشه پروژه و کلید SSO را از `config.php` سامانهٔ اصلی در پوشه‌های والد پیدا می‌کند؛ بنابراین فایل‌ها را در ساختار اصلی پروژه نگه دارید.

برای PHP Worker و سرویس C#، سفارش با `cod_meli` و تاریخ واقعی غذا در `tarikh_entekhabi` تطبیق می‌شود؛ مقدار `roz_entekhabi` روز هفته است و نباید به‌عنوان تاریخ به کار رود. غذای ناهار از `nahar_entekhabi` خوانده می‌شود؛ `naam` و `famili` برای نمایش، `d` برای تاریخ رزرو و `s` برای ساعت رزرو هستند. فیلد شام لازم نیست و کد پرسنلی در جدول سفارش استفاده نمی‌شود. مسیر تردد و فهرست کارکنان نیز باید جداگانه تنظیم باشند.

## چاپگر

چاپگر شبکه را ابتدا در Windows نصب کنید. در پنل، گزینهٔ «دریافت چاپگرهای نصب‌شده» را بزنید و صف موردنظر را انتخاب کنید. روش پیشنهادی `windows-spooler` است.

## Excel

سرویس .NET بدون نصب Excel یا کتابخانهٔ Excel اضافی، فایل استاندارد `.xlsx` را در `exportPath` می‌سازد. مسیر باید روی همان سروری باشد که سرویس اجرا می‌شود.

## نکتهٔ مهم

صفحهٔ مستقل با بازکردن مستقیم `index.html` برای پیش‌نمایش کار می‌کند. برای اتصال واقعی Access، پایش خودکار، چاپگر نصب‌شده و ذخیرهٔ Excel در مسیر سرور، باید `start_food_ticket.bat` اجرا باشد. برای دسترسی از رایانه‌های دیگر، فقط روی شبکهٔ مدیریتی و پشت HTTPS تنظیم کنید؛ سرویس به‌تنهایی TLS ارائه نمی‌کند. SQLite زیر `%LOCALAPPDATA%` حساب اجراکننده ذخیره می‌شود. رمزها با DPAPI در سطح ماشین رمز می‌شوند؛ دسترسی خواندن فایل تنظیمات را به مدیران/حساب سرویس محدود کنید، چون کاربران دیگر همان ماشین ممکن است بتوانند آن‌ها را رمزگشایی کنند.
